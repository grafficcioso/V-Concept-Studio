V-Concept Studio 개인정보처리방침

V-Concept Studio(PC 프로그램과 웹앱)는 개인이 자신의 작업용으로 쓰는 도구입니다. 개발자는 별도 서버를 운영하지 않으며, 사용자의 데이터를 수집하거나 보관하지 않습니다.

구글 드라이브

사용자가 동기화를 켜면, 앱은 drive.file 권한으로 앱이 직접 만든 폴더와 파일(생성 결과 이미지와 에셋)에만 접근합니다. 드라이브의 다른 파일은 읽거나 바꾸지 않습니다. 이 데이터는 사용자의 구글 드라이브와 사용자의 기기에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

OpenAI API

이미지 생성을 위해 사용자가 고른 이미지와 지시문이 사용자 본인의 API 키로 OpenAI 에 직접 전송됩니다. API 키는 사용자의 기기(Windows 자격 증명 관리자 또는 브라우저 저장소)에만 저장됩니다.

연결 해제

앱의 [연결 해제] 버튼이나 구글 계정 → 서드파티 앱 액세스에서 언제든 권한을 취소할 수 있습니다.

GitHub Issues

Privacy Policy (English). V-Concept Studio is a personal tool with no developer-operated server. When Google Drive sync is enabled it uses the drive.file scope to access only the folder and files the app itself creates (generated images and assets). Data stays in the user's own Google Drive and devices and is never sent to the developer or third parties. Images and prompts are sent directly to OpenAI with the user's own API key. Access can be revoked anytime from the app or Google Account permissions.
