# V-Concept Studio 변경 내역

## v0.3.0 (2026-11-14)

**이름 변경**: Character Reference Studio → **V-Concept Studio**. 기존 프로젝트·라이브러리·프롬프트·API 키는 자동으로 옮겨집니다.

**새 기능**
- **부분 수정**: 결과에서 마음에 안 드는 곳을 빨간 반투명 펜으로 칠하고 "머리카락 가닥 줄여줘", "원화 느낌 더 살려줘" 같은 요청을 보낼 수 있습니다. 원본 원화를 참조로 함께 보낼 수 있습니다.
- **파트 사면도**: 파트 분할 결과에서 헤어·헤드·액세서리 중 하나만 칠해 그 파트만 4방향으로 돌립니다. 칠한 부분만 잘라서 보내며, 파트 종류별 전용 프롬프트를 씁니다.
- **화풍 프롬프트 추출**: 이미지의 화풍을 분석해 영문 화풍 프롬프트와 한국어 요약을 만들고, 화풍 프리셋으로 저장해 모든 생성에 붙일 수 있습니다. (텍스트 모델 사용, 1회 약 1센트 미만)
- **이미지 복사**: 결과·원본·라이브러리·조합 결과를 클립보드에 복사 (버튼, Ctrl+C, 우클릭 메뉴)
- **충전액·추정 잔액 표시**: 충전한 금액을 입력하면 상단에 "충전 − 앱 기록 사용액 = 추정 잔액"을 보여 주고, OpenAI 결제 페이지를 바로 열 수 있습니다.
- **자동 업데이트**: 실행할 때 새 버전을 확인하고, 업데이트 후 바뀐 점을 알려 줍니다.

**바뀐 점**
- 생성 기록 아래 버튼을 두 줄로 정리하고, 결과 우클릭 메뉴를 추가했습니다.
