# V-Concept Studio 변경 내역

## v0.6.0 (2026-11-25)

**새 기능 — 헤드·헤어 크기 맞추기**
- 파트 사면도의 파트 종류에 **헤드+헤어 세트**가 생겼습니다. [헤드]로 민머리를, [헤어]로 가발을 따로 칠하면(다른 쪽은 파랑으로 보임) 헤드 사면도를 먼저 만들고, 그 결과를 크기 기준으로 넣어 헤어 사면도를 이어서 만듭니다. 머리 크기·눈선·턱선을 맞추라고 지시합니다. (유료 2장, 헤드가 실패하면 헤어는 보내지 않음)
- 헤어만 돌릴 때도 이미 만든 **헤드 사면도를 크기 기준**으로 고를 수 있습니다 (같은 원본에서 나온 최신 헤드 사면도가 기본).
- 결과 목록 오른쪽 클릭 → **헤드와 겹쳐 보기**: 헤어 사면도를 헤드 사면도 위에 반투명으로 겹쳐 어긋났는지 확인합니다.
- AI가 크기를 완벽히 맞춘다는 보장은 없습니다. 겹쳐 보기로 확인해 주세요.

**새 기능 — 핀터레스트 가져오기**
- 상단 **핀터레스트…** 버튼: 공개 보드 주소를 저장해 두고 [핀 불러오기]로 최근 핀(약 25개)을 봅니다. 날짜로 고르거나 직접 체크해 원본 크기로 가져옵니다. 이미 가져온 핀은 다시 가져오지 않습니다.
- 가져온 뒤 **정면화 / 사면도 / 정면화 → 사면도**를 이어서 만들 수 있습니다. 시작 전에 장수·예상 비용을 한 번 묻고, 실패하면 거기서 멈춥니다.
- 가져온 이미지에는 **'외부 출처' 태그와 출처 메모**가 붙습니다 — 공부·참고용, 판매·커미션·게시 금지.
- 공개 보드만 됩니다 (핀터레스트 RSS, 무료). 핀터레스트가 RSS를 바꾸면 안 될 수 있습니다.
- Claude 연결: "11월 20일부터 추가된 핀 다 정면화해 줘" → 먼저 장수·예상 비용을 보여 주고, OK 하면 진행합니다 (1번 최대 장수·하루 상한 그대로).

**폰 웹앱 v0.4.0**
- 폰에서도 **파트 사면도**(헤어·헤드·액세서리·기타)와 **헤드+헤어 세트**, **헤드와 겹쳐 보기**를 쓸 수 있습니다. 결과 화면의 [◧ 파트 사면도]를 누르세요.

## v0.5.0 (2026-11-15)

**새 기능 — Claude Code 연결 (MCP 모드)**
- Claude Code 가 이 프로그램의 기능을 도구로 쓸 수 있습니다: 받은 원본 확인, 정면화 → 사면도처럼 여러 단계 이어서 생성, 결과 보기, 이름·태그 바꾸기, 원하는 폴더에 원하는 파일 이름으로 복사(네이밍 정리), 드라이브 동기화.
- Claude Code 의 원격 제어와 함께 쓰면 밖에서 폰의 Claude 앱으로 "받은 원본 사면도까지 뽑아 둬"처럼 시킬 수 있습니다.
- 설정 → **Claude 연결** 에서 켜야 동작합니다(기본 꺼짐). 등록 명령은 [복사] 버튼으로 복사해 붙여 넣으면 됩니다.
- 비용 안전장치: 요청 1번 최대 장수(기본 6장)와 Claude 연결 하루 상한(기본 $2, 앱 추정액)을 넘으면 거절합니다. 월간 예산도 지킵니다.
- 프로그램 창을 켜 두지 않아도 동작하고, 켜 두면 Claude 가 만든 결과가 몇 초 안에 목록에 나타납니다.

**새 기능 — 폰에서 PC로 원본 보내기**
- 폰 웹앱의 생성 화면 → **PC로 원본 보내기** 에서 여러 장을 골라 프로젝트 이름·메모와 함께 보냅니다.
- PC는 다음 동기화 때 받아서 해당 프로젝트(없으면 '폰에서 받은 원본')에 원본으로 넣고, 드라이브 사본은 휴지통으로 옮깁니다.
- Claude 연결에서는 '받은 원본'과 메모를 볼 수 있고, 처리하면 '처리됨'으로 표시됩니다.

**기타**
- 업데이트할 때 Claude Code 연결이 잠시 끊깁니다. Claude Code 에서 /mcp 로 다시 연결하세요.

## v0.4.1 (2026-11-15)

**프롬프트를 Positive / Negative 로 나눴습니다**
- 설정 → 프롬프트 · 프리셋 에서 **Positive(만들고 싶은 것)** 와 **Negative(나오면 안 되는 것)** 를 따로 편집합니다.
- 모든 기본 프롬프트에 Negative 를 정리해 넣었습니다(예: 정면화 — 3/4 view, head tilt, cropped hair …).
- 보낼 때는 Positive → 화풍 → Negative 순서로 붙습니다. OpenAI 이미지 API 에 별도 negative 칸이 없어서, Negative 는 '다음은 나오면 안 됨' 문단으로 맨 끝에 들어갑니다.
- 직접 고치지 않은 기본 프롬프트는 새 버전으로 자동 교체되고, 직접 고친 프롬프트와 프리셋은 그대로 둡니다.

## v0.4.0 (2026-11-15)

**새 기능 — 구글 드라이브 동기화**
- PC 프로그램과 폰 웹앱이 같은 구글 드라이브 폴더("V-Concept Studio 동기화")로 **생성 결과와 에셋**을 주고받습니다. 받은 항목은 각 앱의 기록·라이브러리에 바로 나타납니다.
- 설정 → **구글 드라이브** 에서 클라이언트 ID·보안 비밀번호를 넣고 [연결] 을 누르세요. 비밀번호와 로그인 정보는 Windows 자격 증명 관리자에만 저장됩니다.
- 생성·수정 후 자동으로 동기화합니다(끌 수 있음). 위쪽 ☁ 버튼으로 바로 동기화할 수도 있습니다.
- 한쪽에서 지우면 드라이브 휴지통(30일 복구 가능)으로 옮겨지고 다른 기기에서도 지워집니다. 이름·태그·즐겨찾기는 나중에 고친 쪽이 남습니다.
- 앱이 만든 파일만 다루는 권한(drive.file)만 사용합니다. 드라이브의 다른 파일은 보지 않습니다.

## v0.3.4 (2026-11-15)

**고친 점 — 화면 멈춤 ("응답 없음")**
- 보내 주신 멈춤 기록(덤프)으로 원인을 찾았습니다. 결과 화면에 **투명 배경 이미지**를 창 크기에 맞출 때, Qt 가 그림의 불투명 픽셀 외곽선 전체를 계산하고 Windows 11 스타일의 스크롤바 크기를 다시 계산하는 과정을 반복하며 몇 초~수십 분씩 멈췄습니다.
- 이제 이미지 사각형 기준으로 맞추고, 결과 화면의 스크롤바를 없앴습니다(드래그로 이동, 휠로 확대·축소는 그대로). 창 크기가 실제로 바뀔 때만 다시 맞춥니다.

## v0.3.3 (2026-11-15)

**고친 점**
- 업데이트 직후 등, 설정 파일을 다른 프로그램(백신·동기화)이 잠깐 잡고 있으면 프로그램이 시작하지 못하고 꺼지던 문제를 고쳤습니다. 몇 번 다시 시도하고, 그래도 안 되면 멈추지 않고 계속 실행합니다.
- 프로그램을 두 개 동시에 켤 수 없게 했습니다. 이미 실행 중이면 안내만 띄웁니다. (두 개가 같은 데이터를 동시에 쓰면 충돌합니다.)

**멈춤 원인 찾기용 진단 강화**
- 화면 처리 하나가 1초 넘게 걸리면 어떤 화면 요소의 어떤 처리였는지 `logs\hang.log`에 기록합니다.
- 화면이 멈추면 그 순간의 상태를 `logs` 폴더에 `hang_날짜.dmp` 파일(수백 KB 이하)로 저장합니다. 멈춤이 생기면 hang.log 와 이 파일을 보내 주세요.

**고친 점**
- 투명 배경 이미지(예: 배경을 transparent 로 만든 파트 분할 결과)를 입력으로 부분 수정·사면도 등을 하면 결과에 검은 배경, 회색 얼룩, 빛 번짐이 생기던 문제를 고쳤습니다. 이제 투명 부분을 흰 배경과 합친 사본을 보냅니다. (저장된 원본 파일은 바뀌지 않습니다.)

## v0.3.1 (2026-11-14)

**고친 점**
- 일부 PC에서 "업데이트 완료" 창을 닫으면 프로그램이 응답 없음으로 멈추던 문제를 막았습니다. 안내 창이 프로그램을 붙잡지 않는 일반 창으로 뜨고, 한 번 보여 준 뒤에는 다시 뜨지 않습니다.
- 예전 데이터 폴더(문서\CharacterReferenceStudio) 이름 바꾸기에 실패했으면 다음 실행 때 다시 시도합니다.
- 업데이트 확인 창도 프로그램을 붙잡지 않는 방식으로 바꿨습니다.

**진단 기능**
- 화면이 8초 이상 응답하지 않으면 그 순간의 상태를 `logs\hang.log`에 자동으로 기록합니다. 멈춤이 생기면 이 파일을 보내 주세요.

## v0.3.0 (2026-11-14)

**이름 변경**: Character Reference Studio → **V-Concept Studio**. 기존 프로젝트·라이브러리·프롬프트·API 키는 자동으로 옮겨집니다.

**새 기능**
- **부분 수정**: 결과에서 마음에 안 드는 곳을 빨간 반투명 펜으로 칠하고 "머리카락 가닥 줄여줘", "원화 느낌 더 살려줘" 같은 요청을 보낼 수 있습니다. 원본 원화를 참조로 함께 보낼 수 있습니다.
- **파트 사면도**: 파트 분할 결과에서 헤어·헤드·액세서리 중 하나만 칠해 그 파트만 4방향으로 돌립니다. 칠한 부분만 잘라서 보내며, 파트 종류별 전용 프롬프트를 씁니다.
- **화풍 프롬프트 추출**: 이미지의 화풍을 분석해 영문 화풍 프롬프트와 한국어 요약을 만들고, 화풍 프리셋으로 저장해 모든 생성에 붙일 수 있습니다. (텍스트 모델 사용, 1회 약 1센트 미만)
- **이미지 복사**: 결과·원본·라이브러리·조합 결과를 클립보드에 복사 (버튼, Ctrl+C, 우클릭 메뉴)
- **충전액·추정 잔액 표시**: 충전한 금액을 입력하면 상단에 "충전 − 앱 기록 사용액 = 추정 잔액"을 보여 주고, OpenAI 결제 페이지를 바로 열 수 있습니다.
- **자동 업데이트**: 실행할 때 새 버전을 확인하고, 업데이트 후 바뀐 점을 알려 줍니다.

**바뀐 점**
- 생성 기록 아래 버튼을 두 줄로 정리하고, 결과 우클릭 메뉴를 추가했습니다.
