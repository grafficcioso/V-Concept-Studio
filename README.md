# V-Concept Studio v0.3.0

Pinterest 등에서 찾은 캐릭터 원화를 넣고 **정면화 · 파트 분할 · 사면도**를 생성해 프로젝트/에셋 라이브러리에 보관하고,
부품을 다시 조합하는 **3D 캐릭터 원화 전처리 프로그램**입니다. (Windows 10/11, 한국어 UI, OpenAI 공식 이미지 API 사용)
구 이름: Character Reference Studio (원화 제조기)

> AI 결과는 원본과 100% 동일하지 않을 수 있습니다. 사면도의 뷰 간 일관성, 파트 분할 시트의 완전한 분리도 보장되지 않습니다.

---

## 1. 설치 · 업데이트

### 처음 설치
1. [Releases 페이지](https://github.com/grafficcioso/V-Concept-Studio/releases)에서 최신 버전의 **`VConceptStudio-windows.zip`** 을 받습니다.
2. 압축을 풀어 **문서나 바탕화면 같은 내 폴더**에 둡니다. (Program Files 처럼 쓰기 권한이 필요한 곳에 두면 자동 업데이트가 안 됩니다.)
3. `VConceptStudio\VConceptStudio.exe` 실행. 서명되지 않은 프로그램이라 처음에 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

### 자동 업데이트
- 프로그램을 켤 때 새 버전이 있으면 "업데이트할까요?" 창이 뜹니다. [업데이트]를 누르면 내려받고 해시를 검증한 뒤,
  프로그램을 닫고 파일을 교체해 다시 실행합니다. 처음 켜질 때 **바뀐 점**을 보여 줍니다.
- 프로젝트·라이브러리·프롬프트·API 키는 프로그램 폴더 밖에 저장되므로 업데이트해도 유지됩니다.
- 설정 → 업데이트에서 자동 확인을 끄거나, 지금 확인하거나, 변경 내역을 볼 수 있습니다.

### 새 버전 배포(개발자용)
`crs/__init__.py` 의 `APP_VERSION`을 올리고 `defaults/CHANGELOG.md` 에 그 버전 내용을 적어 **main 에 푸시**하면,
GitHub Actions(`.github/workflows/build-release.yml`)가 테스트 → EXE 빌드 → 기동 확인 → zip·sha256 → 릴리스(태그 포함) 게시까지 자동으로 합니다.
버전을 올리지 않은 푸시는 빌드·테스트만 하고 릴리스는 만들지 않습니다.

### 직접 빌드 (선택)
Python 3.12/3.13 설치 후 `build_windows.bat` 실행 → `dist\VConceptStudio\VConceptStudio.exe`.
빌드 없이 소스로 실행하려면 `run_dev.bat`.

## 2. OpenAI API 키 발급 · 등록

1. <https://platform.openai.com> 로그인 → **API keys**에서 키 생성 (`sk-…`). 결제 수단/크레딧 등록이 필요합니다.
2. 일부 이미지 모델은 **조직 인증(Organization Verification)** 이 필요할 수 있습니다.
3. 앱에서 **설정 → API** → 키 붙여넣기 → **키 저장** → **연결 테스트(무료 조회)**.

- 키는 **Windows 자격 증명 관리자(Credential Manager)** 에만 저장됩니다(`keyring`). 설정 파일·DB·로그·프로젝트 파일·이미지에는 기록하지 않습니다.
- 보안 저장소를 쓸 수 없는 PC에서는 디스크에 쓰지 않고 실행 중에만 메모리에 보관합니다.
- 키가 없어도 이미지 관리, 라이브러리, 수동 조합, 내보내기는 모두 동작합니다(오프라인 가능). API는 **생성 버튼을 눌렀을 때만** 호출됩니다.
- **데모 모드**(설정 → API): API를 호출하지 않고 화면 흐름만 확인합니다. 비용이 없고, 결과는 "DEMO" 표시가 들어간 가짜 이미지입니다.

## 3. 사용법

**기본 흐름**
1. **새 프로젝트** → 원화를 **끌어다 놓기 / 원본 열기 / Ctrl+V 붙여넣기** (PNG·JPG·WEBP).
2. 오른쪽 패널에서 **정면화** 선택 → 모델·품질·크기 확인 → **생성** → 예상 비용 확인 창에서 진행.
3. 하단 **생성 기록**에서 마음에 드는 결과에 **★ 즐겨찾기**, **이름·태그** 지정.
4. **입력으로 사용 →** 을 눌러 그 결과를 다음 작업(파트 분할, 사면도)의 입력으로 지정.
5. 파트 분할 시트는 **잘라서 에셋 등록…** 으로 부품 영역을 하나씩 드래그해 라이브러리에 저장(선택적으로 단순 배경 제거).
6. 결과에서 마음에 안 드는 곳이 있으면 **✎ 부분 수정…** → 빨간 반투명 펜으로 영역을 칠하고 요청(예: "머리카락 가닥 줄여줘", "원화 느낌 더 살려줘")을 적어 보냅니다.
   칠한 영역은 OpenAI의 markup(주석 레이어)으로 전송되며, 원본 원화를 참조로 함께 보낼 수 있습니다. 영역은 '안내'라서 경계가 정확히 지켜지지 않을 수 있습니다.
   (GPT-Image-2.5/2.6 계열만 영역 지정 지원. 칠하지 않으면 전체 수정 요청)
7. 파트 분할 결과에서 **파트 사면도…** → 돌릴 파트(헤어/헤드/액세서리)만 칠하고 종류를 고르면, 칠한 부분만 잘라 그 파트만 4방향으로 만듭니다.
8. **화풍 추출…** → 이미지의 화풍을 영문 프롬프트로 뽑아 화풍 프리셋으로 저장하고, 생성 패널의 **화풍** 목록에서 고르면 모든 생성에 붙습니다.
   (텍스트 모델 GPT-6 Luna 사용, 1회 1센트 미만 예상)
9. 결과·원본·에셋·조합 결과는 **복사(Ctrl+C)** 로 클립보드에 넣어 포토샵 등에 바로 붙여넣을 수 있습니다.
10. **조합** 탭에서 부품을 올려 위치/크기/회전/순서를 맞추고 **합성 PNG 내보내기** 또는 **AI 조합**.

| 화면 | 기능 |
|---|---|
| 생성 | 원본/결과 비교(휠 확대·축소, 맞춤, 100%), 기능 버튼(정면화·파트 분할·사면도 + 홍채 복원·업스케일), 프리셋, 모델/품질/크기/배경, 예상 비용, 요청 취소, 생성 기록, PNG 저장, 즐겨찾기, 에셋 등록, 부분 수정(빨간 펜 영역 지정), 삭제 |
| 에셋 라이브러리 | Head / Hair / Eyes-Iris / Clothing / Accessories / Character 분류, 검색, 태그, 원본 참조 표시, 조합에 추가, 프로젝트 입력으로 보내기 |
| 조합 | 레이어 추가, 드래그 이동, Ctrl+휠 크기, X/Y/크기/회전 수치 입력, 앞/뒤 정렬, 숨김, 삭제, 캔버스 크기·배경(흰색/투명), 조합 저장/불러오기(JSON), 합성 PNG 내보내기(투명 유지), AI 조합 |
| 사용량 · 비용 | 일/월 합계(앱 추정), 요청별 토큰·추정 비용·요청 ID·상태 |
| 설정 | API 키, 프롬프트/프리셋 편집(저장·복제·삭제·초기화·불러오기·내보내기), 모델·요금표, 월간 소프트 예산, 저장 위치 |

**프롬프트 편집**: 설정 → 프롬프트·프리셋. 기능별 '기본' 프롬프트는 데이터 폴더의 `prompts/*.md` 파일이며 저장 즉시 다음 요청부터 적용됩니다.
모델·품질·크기까지 묶으려면 생성 화면의 **현재 설정을 프리셋으로…** 를 쓰세요.

## 4. 요금 주의사항 (꼭 읽어 주세요)

- 이미지 생성은 **OpenAI 계정에 토큰 단위로 과금되는 유료 기능**입니다. 이 앱 자체는 무료이며 별도 서버가 없습니다.
- 앱에 표시되는 금액은 모두 **앱의 로컬 추정치**입니다.
  - 생성 전 *예상 비용*: 같은 모델·품질·크기의 **실제 사용 기록**이 있으면 그 범위로, 없으면 요금표의 참고 단가로 표시합니다.
    둘 다 없으면 **"정확한 예상 비용 계산 불가"** 로 표시하고 임의의 숫자를 만들지 않습니다.
    (GPT-Image-2.5/2.6은 품질·크기별 공식 출력 토큰 표가 공개되어 있지 않아, 첫 생성 전에는 계산 불가로 나옵니다.)
  - 생성 후 *앱 추정 실제 비용*: API가 돌려준 토큰 사용량 × 요금표 단가.
  - 입력 이미지·텍스트 토큰 등 추가 비용이 있을 수 있고, 실제 청구액과 다를 수 있습니다. 정확한 금액은 OpenAI 대시보드의 Usage에서 확인하세요.
- **모델·요금표**는 설정에서 직접 편집합니다(자동 업데이트 없음). 기본값은 2026-11-11에 OpenAI 공식 문서로 확인한 값이며, 화면에 *최종 확인일*이 표시됩니다.
  새 모델이 나오면 **서버에서 모델 목록 가져오기**로 추가하고 가격은 공식 가격표를 보고 입력하세요(앱이 임의로 채우지 않습니다).
- **충전액·추정 잔액**: OpenAI는 잔액 조회용 공식 API가 없어 자동으로 가져올 수 없습니다. 설정 → 예산 · 충전액에 충전한 금액과 날짜를 넣으면
  "충전 − 이 앱 기록 사용액 = 추정 잔액"을 상단에 보여 줍니다. 다른 앱 사용분은 빠지므로 정확한 잔액은 OpenAI 결제 페이지에서 확인하세요.
- **월간 소프트 예산**은 앱이 기록한 추정 비용 합계로 경고만 합니다. **OpenAI 서버의 청구를 차단하지 않으며**, 다른 앱에서 쓴 금액은 포함되지 않습니다.
  실제 지출 한도는 OpenAI 대시보드(Billing → Limits)에서 설정하세요.
- **자동 재시도 없음**: 네트워크 오류·타임아웃 뒤에는 과금 여부를 알 수 없으므로 앱이 요청을 다시 보내지 않습니다. 이런 요청은 사용량 화면에 "과금 여부 불명"으로 따로 표시됩니다.
- **요청 취소**는 연결을 끊는 방식입니다. 서버에서 이미 처리가 시작됐다면 과금될 수 있습니다.
- 요청당 1장만 생성합니다. AI 조합도 별도의 유료 요청입니다.

## 5. 데이터 저장 위치

기본: `문서\V-Concept Studio\` (v0.2 이하의 `문서\CharacterReferenceStudio\`는 처음 실행할 때 자동으로 옮겨집니다) (설정 → 저장 위치에서 변경, 기존 데이터 복사 지원)

```text
V-Concept Studio/
  projects/<프로젝트>/originals/      가져온 원본 사본 (원본 파일은 건드리지 않음)
  projects/<프로젝트>/outputs/        생성 결과 PNG
  projects/<프로젝트>/thumbs/, compositions/, project.json (메타데이터 사본)
  library/assets/, library/thumbnails/  에셋 라이브러리 (내부 사본 → 원본을 지워도 유지)
  prompts/*.md                         기능별 기본 프롬프트 (직접 편집 가능)
  config/models.json                   모델·옵션·요금표
  data/app.db                          SQLite (이미지 메타데이터·연결 관계·프리셋·사용량)
  logs/app.log                         진단 로그 (API 키 형태 문자열은 자동으로 가림)
```
앱 설정(`settings.json`)은 `%APPDATA%\V-Concept Studio\`에 있습니다. DB에는 상대 경로만 저장하므로 데이터 폴더를 통째로 옮겨도 됩니다.

## 6. 소스 구조

```text
main.py                      실행 진입점
crs/app.py                   QApplication 시작, 전역 예외 처리
crs/config.py                설정(settings.json), 폴더 구조
crs/keystore.py              API 키 보관 (keyring / Windows Credential Manager)
crs/db.py                    SQLite 스키마와 쿼리
crs/workspace.py             프로젝트·이미지·에셋 파일 작업 (UI 없이 테스트 가능)
crs/pricing.py               모델 카탈로그, 옵션 검증, 비용 추정
crs/functions.py             생성 기능 레지스트리 (플러그형)
crs/services/image_service.py  ImageGenerationService — OpenAI Images API 호출, 오류 분류
crs/services/style_service.py  화풍 추출 (Responses API, 이미지 입력 텍스트 모델)
crs/updater.py               GitHub 릴리스 확인·다운로드·해시 검증·교체 스크립트
crs/ui/gen_controller.py     검증 → 비용 확인 → QThread 호출 → 저장/사용량 기록
crs/ui/*.py                  생성 탭, 라이브러리, 조합, 사용량, 설정, 대화상자
defaults/prompts/*.md        내장 영문 프롬프트      defaults/models.json  기본 모델·요금표(이미지·텍스트)
defaults/CHANGELOG.md        변경 내역 (업데이트 안내·릴리스 설명에 사용)
tools/                       릴리스용 스크립트 (버전 확인, 릴리스 설명, zip 패키징)
tests/                       자동 테스트             TESTING.md            수동 테스트 체크리스트
build_windows.bat, crs.spec  Windows 빌드      .github/workflows/  자동 빌드·릴리스
```

**새 생성 버튼 추가(예: 의상 분리)**: `defaults/prompts/<key>.md`에 프롬프트를 넣고 `crs/functions.py`의 `FUNCTIONS`에 한 줄 추가하면
버튼·프롬프트 편집기·프리셋이 자동으로 구성됩니다. 홍채 복원·업스케일이 이 방식으로 들어가 있습니다.

**API 사용 방식**: 공식 Python SDK `client.images.edit(model=…, image=[…], prompt=…, quality=…, size=…, background=…)`.
`auto` 옵션은 전송하지 않고 모델 기본값에 맡깁니다. `max_retries=0`, 타임아웃은 설정값(기본 300초). 응답의 `usage`와 `x-request-id`를 저장합니다.

## 8. 알려진 제한

- 파트 분할 결과는 **시트 한 장**입니다. 개별 부품은 수동 크롭으로 등록하며, 단순 배경 제거는 AI 처리가 아니어서 불완전할 수 있습니다.
- 투명 배경은 모델에 따라 지원되지 않거나 불완전할 수 있습니다.
- 브라우저에서 이미지를 직접 끌어오면 주소만 전달되는 경우가 있습니다. 그때는 '이미지 복사' 후 Ctrl+V를 쓰세요(웹 다운로드/크롤링 기능은 없습니다).
- 제외 범위: PSD 레이어 복원, Blender/Max/Unity 연동, 로컬 생성 모델, 배치 생성.
